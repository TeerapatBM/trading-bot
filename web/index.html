เชื่อมต่อทีละขั้น

  1. 1
    ตรวจแพลตฟอร์มบัญชี XM

    บัญชีต้องเป็น MT5 หากใช้ MT4 ให้เปิดบัญชี MT5 เพิ่มในพื้นที่สมาชิก

  2. 2
    เปิด MT5 แล้วล็อกอิน

    ใช้เลขบัญชี รหัสเทรด และชื่อเซิร์ฟเวอร์ที่ XM ระบุ

  3. 3
    อนุญาตให้บอตเทรด

    เปิด Algo Trading และอนุญาต external Python API ที่ Tools → Options → Expert Advisors

  4. 4
    ติดตั้งตัวเชื่อม และตั้งค่าบอต

    รัน install-mt5.ps1 แล้วเปิดด้วย start.ps1 เลือก XM / MT5 พร้อมกรอก symbol และอัตราเงินบาท

  5. 5
    ตรวจบัญชี แล้วเริ่มบอต

    ตรวจเลขบัญชีและโหมดที่แสดงก่อนเริ่มออเดอร์แรก
